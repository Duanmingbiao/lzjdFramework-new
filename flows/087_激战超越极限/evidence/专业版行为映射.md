# 激战超越极限87专业版行为映射

证据边界：专业版 `root.635` 静态原型。图色主色、偏移色、方向、相似度、点击偏移和等待值保持一致；全屏搜索区仅展开为项目坐标 `0,0,719,1279`。这是静态重建证据，不等于当前设备运行证明。

| 阶段 | 专业版行为 | 本项目实现 |
|---|---|---|
| 入口 | 强敌入袭页向下寻找；双色入口；任务页、已完成页、灰色未开放分别判定 | `087_入口*`、`087_任务页*`、`087_已完成*`、`087_未开启*` |
| 支援 | 最多10个完整的支援、邀请、返回、战斗、继续周期；未知页面不计轮次 | 独立阶段循环；保留 `(-160,-770)`、`(-160,-350)`、`(+64,+29)` 点击链；不可邀请区分0ms/200ms；返回按钮先等待1500ms再点击等待500ms，确认任务页后开战 |
| 战斗入口 | 战斗按钮前5次点 `(+190,+12)`，之后点锚点；识别开战页 | `battleClicks < 5` 与 `087_点击战斗/087_开战页*` |
| 开战 | 目标6；固定点击 `(398,982)`、`(587,982)`，各500ms；随后处理跳过 | 目标6沿用相同模板；跳过独立使用root.725基准模板，偏移(-310,+93)，50ms后再等3000ms，不使用152跳过 |
| 结果 | 成功一2000ms、成功二1000ms；战斗内失败明确结束；继续阶段失败只关闭弹窗 | 区分战斗与继续阶段，按各自出口处理，不合并失败语义 |
| 继续 | 成功页后识别继续任务或已完成页 | `087_继续任务*` / `087_已完成*` |
| 奖励 | 已完成页点 `(+475,-975)`；处理奖励弹窗，灰色优先蓝色领取 | 满10轮后仍进入奖励识别，不按轮次提交；灰色领取才结束 |

项目公共边界：业务函数只置终态；仍须公共 `ReturnToHall()` 连续确认后由 `CommitTask(True)` 提交。超时、前台中断或未知页面不提交，保存任务87并恢复。未改旧工程，未操作手机助手 UI。
